What is this site?

Prompt-Library is a curated, growing collection of production-grade security & engineering prompts for Next.js + MongoDB web builders — authored as Markdown + Obsidian Canvas, bilingual (English → Persian), and published as real static pages: every prompt gets its own URL, unique meta tags, JSON-LD and a sitemap entry.

پرامپت‌لایبرری مجموعه‌ای منتخب و در حال رشد از پرامپت‌های امنیتی و مهندسیِ آماده‌ی کار برای سازندگان وب با Next.js + MongoDB است — به‌صورت Markdown و Obsidian Canvas نوشته می‌شود، دوزبانه است (انگلیسی → فارسی) و به‌صورت صفحات استاتیک واقعی منتشر می‌شود: هر پرامپت URL و متای اختصاصی و JSON-LD و ورود به sitemap دارد. بدون فریم‌ورک، بدون ردیابی — فقط HTML و CSS و JavaScript خالص.

How publishing works

01
AuthorWrite

Write a .md (with front-matter) or an Obsidian .canvas file inside prompts/<category>/ — the folder is the category.

02
Push to mainBuild

A GitHub Action runs the static generator (tools/build.mjs — pure Node, no dependencies).

03
Real pages shipLive

Every prompt gets a card, its own page (/category/slug/), unique meta tags, JSON-LD and a sitemap entry — automatically.
