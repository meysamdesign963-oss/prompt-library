About this library

A curated, growing collection of production-grade prompts and engineering specs. Every entry is bilingual — English first, then Persian — stored as an interactive Obsidian JSON Canvas, and written to be handed straight to a developer or an AI coding agent.

Open source Bilingual FA · EN JSON Canvas Agent-ready

Use it as a prompt

$ git clone https://github.com/meysamdesign963-oss/prompt-library.git
$ open Prompt-Library.canvas → Obsidian / any JSON Canvas app
Then paste the spec into your AI agent — Claude · Cursor · Copilot
